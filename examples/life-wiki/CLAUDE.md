# 이 저장소의 규칙

- 개인 생활 위키다. 글은 한국어로 쓴다.
- 새 메모는 inbox/YYYY-MM-DD.md, 정리한 글은 주제 폴더(요리, 여행, 읽은-책, 업무-메모)에 둔다.
- 글 맨 위에는 날짜, 출처, 태그 줄을 둔다.
- 파일을 옮기거나 합치면 README.md 목차를 같이 고친다.
- 내 문장은 고치지 말고 위치만 옮긴다.
- 배지는 README.md 와 폴더 README.md 에만 단다. 노트 파일에는 달지 않는다.
- 글을 더하거나 옮기면 README 맨 위의 글 수와 주제별 글 수 배지, 모든 글 표, 폴더 README 의 글 수와 수정 날짜 배지를 같이 고친다.
- 배지 색은 README.md 의 「배지 색 규칙」 표를 따른다.
